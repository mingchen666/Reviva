# 内置创作 Agent 的有效工具配置

日期：2026-08-02  
状态：已确认

## 问题

Agent 编辑弹窗允许用户编辑内置 Agent 的 `tools`，但创作中心结构化任务和 DeepAgent 任务仍有路径直接读取磁盘内置配置。结果是用户移除联网工具后，运行时仍可能按内置默认 Exa 或网页读取路径联网，UI 配置与实际权限不一致。

## 决策

新增统一的“有效内置 Agent 配置”解析层：官方 `config.json` 是基线，数据库中该内置 Agent 的用户覆盖是唯一运行时覆盖来源。结构化创作任务与 DeepAgent 内置任务都通过它取配置，保存后下一次任务立即生效，无需重启。

内置 Agent 的数组型覆盖改为同时保存 `added` 与 `removed`。这使用户可以移除官方工具，并且内置模板升级时不会把已移除的工具重新加入；旧的只含 `added` 的数据继续兼容。

## 联网规则

1. 官方内置创作 Agent 默认绑定 `mcp:exa`，作为默认联网搜索提供者。
2. 本次生成的“联网”开关和 Agent 的 `permissions.webSearch` 都是总开关；二者任一关闭，禁止联网。
3. 实际可用搜索提供者只由有效 `tools` 推导：`mcp:exa`、`web_search_bing`、`web_search_searxng`、`web_search_tavily`。不再因默认优先级自动补回未绑定的提供者。
4. 网页原文读取同样只使用已绑定的读取工具（例如 `mcp:jina-mcp-server`）。用户未绑定读取器时，不以内部 HTTP 兜底绕过工具设置；Agent 可以只基于搜索摘要继续完成。
5. 若本次开关开启但 Agent 没有任何绑定的搜索工具，任务继续使用本地资料、知识库、Wiki 或主题生成，并返回清晰的“该 Agent 未绑定联网搜索工具”状态。

## 范围

- 结构化创作器（导图、图谱、闪卡、测验、图表、Q&A、术语表、速查表）统一遵循有效配置。
- PPT 与深度研究等 DeepAgent 内置任务统一遵循有效配置。
- 编辑弹窗无需新增另一套联网设置；工具列表就是能力选择，单次生成弹窗保留按需联网开关。

## 验证

仅做定向静态检查和小型 mock 覆盖验证：配置覆盖、`added/removed` 合并、无绑定工具时不调用联网搜索、Exa 默认绑定时可调用。不会运行完整 build。
