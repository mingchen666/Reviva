# 速查表预览布局收敛设计

## 目标

把速查表预览收敛为适合弹窗阅读的章节文档：公式和长内容优先获得正文宽度，章节导航只承担定位职责。

## 布局

- 容器宽度达到 820px 时，显示左侧章节目录与右侧单栏正文。
- 窄容器不显示侧栏，改为顶部横向滚动的章节条。
- 正文始终为单栏，不再根据宽度切成多栏，避免公式、长标题和 Markdown 块在狭窄列中失衡。
- 左侧目录保留当前章节高亮与平滑跳转；不显示浏览进度、类型圆点或回到顶部按钮。

## 删除的行为

- 删除打印 / PDF 按钮、`window.print()` 和所有 print 专用 CSS。
- 删除顶部类型筛选、逐条复制、浏览进度、回顶按钮和底部快捷键提示。
- 删除仅用于上述行为的状态、事件与样式。

## 保留的行为

- 保留 Markdown 与 LaTeX 渲染、深浅主题、章节跳转、当前章节高亮和可访问的按钮语义。
- 保留条目类型的图标、色条和文本标签，用于快速扫描内容类型。

## 验证

仅做定向 Vue SFC 解析、导入检查和 diff 检查；不运行 build 或全量测试。
