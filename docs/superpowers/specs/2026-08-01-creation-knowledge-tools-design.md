# 创作中心知识工具设计

日期：2026-08-01
状态：已确认，待实施计划

## 目标

在创作中心新增三个内置结构化知识工具：

- Q&A 问答卡（FAQ 速查 / 启发思考两种模式）
- 术语表（Glossary）
- 速查表（Cheat Sheet）

它们需要复用现有异步生成、任务、成果和参考资料展示链路；可选地使用当前工作台选中的本地文件、云知识库和本地 Wiki，也可只根据主题生成。用户可以在设置中控制创作中心工具的显示、隐藏和顺序。

## 非目标

- 本期不开放用户自定义创作工具。
- 本期不迁移现有导图、图谱、闪卡、测验、图表、PPT、播客和深度研究到 Wiki 来源能力；只为后续迁移建立共享契约。
- 不为每条问答、术语或速查项保存单独来源引用。
- 不保存完整联网搜索结果到本地数据库。

## 范围与分批策略

采用“共享底座、三项工具先落地”的策略：

1. 为所有生成任务定义统一的 `sourceScope` 数据契约，并建立共用来源收集、结构化 JSON 解析与校验能力。
2. Q&A、术语表、速查表完整使用这条能力并提供独立预览器。
3. 现有创作工具保持行为不变；三项工具稳定后，在后续迭代中逐个接入同一来源契约与 Wiki 检索能力。

## 总体架构

```text
工作台主题与可选来源
  -> sourceScope 快照
  -> EvidenceCollector
  -> 对应内置 Agent / 提示词
  -> StructuredArtifactRunner
  -> JSON 解析、jsonrepair、Schema 与业务校验
  -> tasks + artifacts
  -> 工具专属预览器
```

### 创作工具注册表

新增单一的 `CreationToolRegistry`，作为创作中心的唯一工具定义来源。每项至少包含：

- `id`、`name`、`description`、`icon`、`color`
- `agentEnglishName`、`artifactType`
- 对应配置弹窗和成果预览器
- 默认顺序和来源能力标记

`BuiltinTools.vue`、工作台弹窗分发、成果类型映射和“创作工具”设置页均从该注册表读取。它与现有 Agent 工具管理中的 `builtinTools` 完全分离，后者不承担创作中心显示配置。

本期新增标识固定为：

| 工具 | toolId / artifactType | 内置 Agent |
| --- | --- | --- |
| Q&A 问答卡 | `qa` | `qa-generator` |
| 术语表 | `glossary` | `glossary-generator` |
| 速查表 | `cheatsheet` | `cheatsheet-generator` |

## 来源与上下文工程

每次任务持久化如下来源快照：

```json
{
  "ctxItems": [],
  "wikiIds": [],
  "web": { "enabled": false, "provider": "auto" }
}
```

`ctxItems` 包含当前工作台选中的可读本地文件和云知识库/云文档；`wikiIds` 仅允许读取聊天区域已选择的本地 Wiki；`web` 为本次任务的联网选择。

来源是可选的。提交条件为“有主题”或“至少有一个可用来源”；两者都为空时不创建任务。

`EvidenceCollector` 按下列优先级构造带类型标识的证据包：

1. 用户选中的本地文件和本地 Wiki 是主要依据。
2. 选中的云知识库和云文档用于补充检索。
3. 用户主动开启联网后，网页结果仅补充空白、时效性信息或必要背景，不能无提示地覆盖本地来源。

所有读取和检索均有来源数与字符预算，避免长资料直接挤占模型上下文。本地 Wiki 只能在用户选择的范围内进行只读查询。联网查询使用脱敏后的主题和意图，不发送本地路径、原文、个人信息或凭据。

联网默认关闭。开启后默认提供商为 `auto`，优先级为 Exa、Bing、SearXNG、Tavily；用户可在本次生成中改选已配置的提供商。没有可用提供商或请求失败时，任务继续依据已有本地证据或主题生成，并在进度/结果中说明联网未生效。

## Agent 与提示词工程

三个 Agent 均采用现有内置生成模块目录结构：`config.json`、`orchestrator.md` 和 `artifact-rules.json`，由通用 JSON 生成器执行。提示词由三层组成：

1. **共享约束**：来源优先级、禁止虚构、篇幅与去重规则、只输出一个 JSON 对象。
2. **工具专属规则**：按工具的学习/查询目标规定覆盖范围与内容质量。
3. **用户配置**：主题、模式、数量、侧重点、来源和联网选项。

专属检索意图如下：

| 工具 | 重点 |
| --- | --- |
| Q&A | 定义、为什么、如何、常见误解、可追问点 |
| 术语表 | 专业术语、缩写、别名、定义、上下文和易混概念 |
| 速查表 | 公式、关键数据、步骤、边界条件和易错点 |

提示词必须指明：没有来源时可使用可靠通用知识；有来源时必须优先忠实于来源；证据不足时简化或省略条目，不把猜测包装成资料结论。

## 成果 Schema 与交互

### Q&A 问答卡

- 默认数量 12，范围 6–24。
- 模式为 `faq` 或 `thinking`，默认 `faq`。
- 成果包含 `title`、`mode`、`total_items` 和 `items`。
- 每个 item 包含 `id`、`question`、`answer`、`key_point`、`tags`。
- FAQ 预览为可搜索的折叠问答；启发思考预览默认显示问题和思路提示，用户主动展开答案。

### 术语表

- 默认数量 20，范围 8–40。
- 成果包含 `title`、`total_terms` 和 `terms`。
- 每个 term 包含 `id`、`term`、`aliases`、`definition`、`context`、`category`、`importance`。
- 预览为可搜索、可按类别筛选的小词典，条目可展开查看上下文解释。

### 速查表

- 用户可提供可选侧重点；默认“均衡”。
- 成果包含 `title`、`summary`、`sections`。
- section 包含 `title` 和 `items`；item 包含 `kind`、`label`、`content`、`note`。
- `kind` 限定为 `formula`、`fact`、`step`、`pitfall`、`rule`。
- 预览为紧凑的一页式信息板，按公式、关键数据、步骤和易错点等区块排布，并提供打印友好样式。提示词限制区块和条目数量，禁止把长摘要伪装成速查表。

所有生成弹窗均展示当前继承的来源清单和共享联网开关；不再各自提供第二套来源选择器。成果预览沿用任务级“参考”入口，不显示逐项引用。

## JSON 质量与失败处理

所有结构化生成结果统一按以下过程处理：

```text
提取候选 JSON
  -> JSON.parse
  -> jsonrepair
  -> JSON.parse
  -> Zod Schema 校验
  -> 工具业务校验
```

使用 `jsonrepair` 的 ESM API：`import { jsonrepair } from 'jsonrepair'`。它只用于语法容错，不能代替语义完整性校验。

业务校验包括非空数组、数量合理、必填字段、枚举合法性、文本非空和工具专属约束。解析或校验失败时，最多进行一次只要求“修复格式和缺失结构”的模型重试；该重试不追加新证据、不改写内容意图。再次失败则任务失败，不创建成果。

异常规则：

- 单个文件读取失败时跳过，继续使用其余证据或主题。
- KB/Wiki 无结果时正常继续，但不得伪称内容来自该来源。
- 模型不可用、JSON 失败或 Schema 失败时以可理解消息标记任务失败。
- 只有通过全部解析与校验的结果才能写入 `artifacts.content`。

## 存储与设置

不新增成果数据表。

- `tasks.params_json` 保存主题、用户配置、`sourceScope` 和联网选择。
- `artifacts` 继续保存 `storage_type: data` 的成果 JSON，新的 `type` 为 `qa`、`glossary` 或 `cheatsheet`。
- `artifact_id` 继续把任务与成果关联，成果弹窗依此读取任务级参考资料。

设置页在“工作台”导航组增加“创作工具”页面。设置值 `creationToolPreferences` 的格式固定为：

```json
{
  "order": ["quiz", "flashcard"],
  "hiddenIds": []
}
```

页面展示注册表中的全部内置创作工具，支持开关、拖拽排序和“恢复默认”。新版本新增的工具自动追加到既有用户排序末尾；无效 ID 自动忽略。该设置只影响创作中心右侧工具面板。

## 测试与验收

实施需覆盖：

- JSON 正常、围栏、缺引号、尾逗号、截断和不可修复输出。
- 三个 Schema 与业务校验的有效和无效样例。
- 主题生成、单文件、云知识库、本地 Wiki、多个来源和无来源禁止提交。
- 联网关闭、可用、无可用提供商和联网失败回退。
- 工具偏好的默认合并、隐藏、排序、恢复默认与新工具追加。
- 三个预览器的结果解析、搜索/展开/筛选和任务级参考入口。

验收顺序为：共享底座、Q&A、术语表、速查表、创作工具设置页与最终集成。现有创作工具不得因本期改动改变其当前生成或展示行为。
