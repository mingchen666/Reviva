# 内置 Skills 搜索设计

## 目标

让用户在 Skills 页的“内置”标签中，按当前选中的分类快速查找技能。搜索应匹配技能标题、ID 与描述，且不改变技能数据或分类选择。

## 范围

- 修改 `src/views/skills/sections/SkillMarket.vue`。
- 在标题栏右上角增加一个紧凑的搜索框，包含搜索图标与有内容时的清空按钮。
- 保持现有分类标签、技能卡片和内置技能数据加载方式不变。

## 交互与布局

- 标题“内置 Skills”保持在标题栏左侧；搜索框置于右上角，宽度约 256px，并可在较窄区域收缩。
- 搜索框高度为 32px，输入文字、搜索图标和清空图标分别使用 12px、14px 和 14px，形成轻微但明显的放大效果。
- 用户输入后立即在浏览器本地过滤当前分类的技能；不会重置或绕过分类标签。
- 搜索文本会先去除首尾空格并忽略大小写，作为一个完整的包含匹配词处理。
- 搜索范围仅包含 `name`、`id`、`desc` 和兼容字段 `description`；不搜索工具名称或 SKILL.md 正文。
- 清空按钮恢复当前分类下的完整列表。

## 数据流

1. 新增搜索输入的响应式状态。
2. 现有 `filtered` 计算属性先按 `activeCat` 筛选，再对每个技能的可搜索字段进行匹配。
3. 搜索仅消费已加载的 `agentsStore.platformSkills`，不增加 IPC、网络请求或持久化状态。

## 空状态与边界

- 当内置技能总数为零时，保留现有“尚未安装内置 Skills”空状态。
- 当存在内置技能、但当前分类和关键词组合没有结果时，显示“当前分类下未找到匹配的内置 Skills”，并提供清空搜索入口。
- 空关键词与只包含空白的关键词均视为未搜索。

## 验收

- 在“全部”及任意具体分类中，标题、ID、描述均能命中对应技能。
- 关键词不会显示其他分类的技能。
- 清空后恢复当前分类全部技能。
- 深色与浅色主题中的输入框、图标、清空按钮和空状态均可辨识。
- 现有无内置技能的安装提示仍能正常展示。

## 非目标

- 不提供跨分类全局搜索、模糊拼音搜索、搜索历史或高亮匹配片段。
- 不修改自定义 Skills 页，也不改动内置技能的安装、启用或绑定行为。
