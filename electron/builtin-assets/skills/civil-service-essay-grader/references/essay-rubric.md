# 申论大作文批改量表

## 九个维度

| 维度 | 核心问题 |
|---|---|
| 立意 | 是否回应题干和材料主旨，是否偏题、窄化、空泛 |
| 总论点 | 是否明确、稳定、可论证 |
| 分论点 | 是否共同支撑总论点，关系是否并列或递进清楚 |
| 结构 | 开头、主体、过渡、结尾是否各司其职 |
| 论证 | 例证、理证、对比、因果是否真正支撑观点 |
| 材料结合 | 是否准确使用材料，避免抄材料或脱离材料 |
| 事实政策 | 案例、数据、政策和讲话是否可靠 |
| 语言 | 是否规范、流畅，避免口语、病句、重复和金句堆砌 |
| 形式 | 标题、字数、分段、手写和卷面是否可执行 |

## 逐段批注模板

```markdown
### 第N段：段落功能
- 有效之处：
- 主要问题：
- 与总论点关系：
- 建议动作：保留 / 删除 / 移动 / 重写
- 局部示例：
```

## 优先级

按影响排序：

1. 偏题或立意错误。
2. 论点和材料不匹配。
3. 结构与论证断裂。
4. 要点与事实问题。
5. 语言和细节问题。

不要先花大量篇幅改词句，却忽略立意和结构。

## 改写边界

- 默认给局部示例，不直接替用户重写全文。
- 用户明确需要范文时，说明示范目的和依据。
- 改写后必须让用户重新提交，才能验证是否掌握。
