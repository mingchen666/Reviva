# 公文与应用文批改量表

## 先识别六要素

1. 文种：通知、倡议书、讲话稿、汇报提纲、短评等。
2. 身份：谁在写。
3. 对象：写给谁看。
4. 目的：宣传、动员、汇报、说明、建议或回应。
5. 内容任务：题干要求覆盖哪些材料要点。
6. 格式限制：完整格式、只写正文、不考虑格式或提纲。

## 格式判断

格式服从题干，不机械套模板。

| 情况 | 处理 |
|---|---|
| 明确“只写正文” | 不因缺标题、称谓、落款扣模拟分 |
| 明确“写提纲” | 重视层次、要点和逻辑，不强求完整公文格式 |
| 完整倡议/公开信 | 检查标题、称谓、正文、倡议动作、落款 |
| 讲话/发言稿 | 检查对象称谓、现场语气、目的和结束表达 |
| 汇报材料 | 检查事实、问题、成效、下一步安排和组织逻辑 |

## 内容检查

- 是否完成题干全部任务。
- 是否将材料要点转化为符合身份和对象的表达。
- 是否只有形式，没有有效内容。
- 是否出现身份越位、语气失当或场景错位。
- 对策和倡议是否具体、可执行并有材料依据。

## 输出顺序

1. 文种与场景判断。
2. 格式问题。
3. 内容要点矩阵。
4. 语言与语气。
5. 局部改写示例。
6. 重写任务。
