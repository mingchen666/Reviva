# 申论小题批改量表

适用于归纳概括、综合分析、提出对策等题型。

## 通用维度

| 维度 | 检查问题 |
|---|---|
| 审题 | 对象、任务动词、材料范围、身份和限定条件是否正确 |
| 要点 | 是否覆盖材料中的核心信息，是否漏点、错点、重复或越界 |
| 加工 | 是否分类、合并、概括，层级和标准是否统一 |
| 表达 | 主体、对象、动作是否清楚，语言是否准确规范 |
| 形式 | 分条、序号、字数和卷面可读性是否符合要求 |

## 题型差异

### 归纳概括

- 优先检查全面性和概括准确度。
- 不把材料原句机械堆叠当成有效概括。
- 同义要点合并，避免一条拆成多条虚增数量。

### 综合分析

- 识别题目要求解释、评价、启示还是关系分析。
- 常见结构：解释对象 → 分析依据/表现/原因/影响 → 结论或对策。
- 结论必须由材料分析推出，不能只复述表面含义。

### 提出对策

- 对策应对应具体问题或原因。
- 保留必要主体、对象、方式和目标。
- 避免“加强宣传、完善制度、提高认识”等无材料支撑的空口号。

## 问题标签

`漏点`、`错点`、`越界`、`重复`、`分类混乱`、`主体缺失`、`动作模糊`、`表达冗余`、`字数风险`。

## 采分点矩阵

```markdown
| 模拟要点/参考要点 | 材料依据 | 覆盖情况 | 表达质量 | 修改建议 |
|---|---|---|---|---|
```

材料依据写原意摘要或可核验位置，不编造段落号和页码。
