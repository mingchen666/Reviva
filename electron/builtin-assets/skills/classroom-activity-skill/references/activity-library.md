# Classroom Activity Library

Choose activities by teaching stage and learning evidence.

## Lesson Opening

### Problem Hook

- Use for math, science, technology, social issues.
- Structure: show conflict/problem -> predict -> reveal key question -> connect to objective.
- Evidence: student prediction or explanation.

### Story / Case Entry

- Use for language, humanities, moral education, training.
- Structure: short case -> personal judgment -> evidence discussion -> lesson problem.
- Evidence: initial claim and reason.

### Quick Retrieval

- Use for review and exam preparation.
- Structure: 3-5 short questions -> peer check -> teacher spot diagnosis.
- Evidence: correct rate and mistake types.

## Concept Formation

### Observe-Compare-Generalize

- Use for math concepts, grammar, science patterns.
- Steps: observe examples -> compare differences -> name common feature -> test with new example.
- Evidence: student-generated rule and counterexample check.

### Prediction-Observation-Explanation

- Use for science demonstrations and simulations.
- Steps: predict -> observe -> explain -> revise.
- Evidence: changed explanation and data support.

### Example / Non-Example Sort

- Use for definitions and classification.
- Steps: sort cases -> justify -> refine criteria -> apply.
- Evidence: classification reason.

## Practice and Transfer

### Peer Instruction

- Use for misconceptions and conceptual questions.
- Steps: individual answer -> peer discuss -> answer again -> teacher explains.
- Evidence: answer shift and discussion reason.

### Error Diagnosis

- Use for math, writing, coding, lab reports.
- Steps: inspect wrong solution -> find error -> explain cause -> correct -> create similar warning.
- Evidence: corrected work and error explanation.

### Mini Project

- Use for technology, arts, science, training.
- Steps: define product -> criteria -> build -> peer feedback -> revise.
- Evidence: product and rubric.

## Closure

### Exit Ticket

- Use for formative assessment.
- Include one core check, one application or explanation, one self-report confusion.

### One-Minute Summary

- Use for concept-heavy lessons.
- Prompt: "今天我学会了... 仍然不确定的是... 一个例子是..."

## Online / Hybrid Activities

- poll before explanation;
- shared document evidence table;
- breakout task with role cards;
- screenshot/short recording as product;
- quiz checkpoint every 8-12 minutes.
