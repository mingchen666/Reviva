# Questioning and Discussion Design

Use this file when the user asks for 提问链, 追问, 讨论问题, 公开课互动, or misconception handling.

## Question Chain Pattern

1. Access question
   - lets most students enter;
   - checks prerequisite or observation.
2. Focus question
   - points to the key concept or conflict.
3. Reasoning question
   - asks why, how, evidence, relation, or process.
4. Transfer question
   - uses a new situation, counterexample, or real-world case.
5. Reflection question
   - asks what changed, what method was used, or what remains unclear.

## Prompt Types

- "你观察到了什么？"
- "哪两个现象/条件不同？"
- "你这样判断的证据是什么？"
- "如果条件改变，会发生什么？"
- "这个答案哪里可能有问题？"
- "有没有反例？"
- "你能用图/表/一句话解释吗？"
- "如果教给同桌，你会怎么说？"

## Handling Student Responses

If answer is correct:

- ask for evidence;
- ask another student to restate;
- ask for a new example.

If answer is incomplete:

- narrow the question;
- provide a hint;
- point to material/evidence;
- ask peer to add.

If answer is wrong:

- treat as useful evidence;
- ask "这个想法从哪里来？";
- use counterexample or demonstration;
- compare wrong and correct reasoning.

## Discussion Quality Checks

- The question has more than one possible thinking route.
- Students have evidence/material to discuss.
- Roles are clear: speaker, recorder, evidence finder, reporter.
- The output is visible: note, chart, answer card, board post, oral claim.
- Teacher has a planned follow-up for likely misconceptions.
