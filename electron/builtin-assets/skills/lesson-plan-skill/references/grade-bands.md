# Grade Band and Subject Adaptation

Use this file when grade, age, student ability, or subject makes a difference.

## Grade Bands

| Band | Design focus | Avoid |
| --- | --- | --- |
| 幼儿/小学低段 | concrete objects, stories, pictures, movement, short tasks, routines, immediate feedback | long abstract explanation, dense text, multi-step written instructions |
| 小学高段 | examples before abstraction, guided discovery, visible thinking, short practice cycles, basic collaboration | too much open-ended inquiry without scaffolds |
| 初中 | concept formation, structured inquiry, misconception diagnosis, examples and counterexamples, peer explanation | only lecture or only drills |
| 高中 | abstraction, proof/reasoning, model building, transfer tasks, exam alignment, error analysis | skipping derivation and thinking process |
| 大学/职教/培训 | outcomes, cases, projects, workplace scenarios, rubrics, portfolio/product evidence | K12-style classroom rituals unless user asks |

## Differentiation Moves

Use at least one when the user mentions mixed ability, weak foundation, gifted students, special needs, large class, or classroom management.

- Content: provide prerequisite review, simplified reading, extension material, or optional challenge.
- Process: use tiered questions, pair support, worked examples, manipulatives, diagrams, or teacher conferencing.
- Product: allow oral explanation, diagram, written solution, slide, model, code, experiment record, or short presentation.
- Support: sentence starters, vocabulary bank, formula card, step checklist, partially completed examples.

## Subject Adaptation

### Chinese / Language

- Include reading purpose, text evidence, vocabulary, expression task, and discussion.
- Use close reading, comparison, retelling, writing transfer, or oral presentation.
- Assessment evidence should cite words/sentences, structure, rhetoric, or argument quality.

### Math

- Include concept origin, representation switch, worked example, variation practice, common mistakes.
- Use concrete-model-symbol progression for younger students.
- For geometry, route visual needs to `edu-solid-geometry` or `edu-analytic-geometry`.

### Science

- Include observation, hypothesis, variables, experiment/simulation, data, conclusion, safety.
- Use prediction-observation-explanation when appropriate.
- For invisible processes, route to `ai-animation-skill` or `learning-visualization-skill`.

### Humanities / Social Studies

- Include source/context analysis, chronology or cause chain, evidence-based discussion, values or civic reasoning when appropriate.
- Avoid presenting contested claims as facts without source basis.

### CS / Technology

- Include concept demo, code or tool practice, debugging, security/ethics notes, and product/task evidence.
- For network protocol or system process, route to `network-protocol-viz`.

### Arts / PE

- Include demonstration, practice criteria, safety, peer feedback, performance/product evidence.
- Keep assessment observable and respectful of individual differences.

## Class Type Adaptation

- 新授课: focus on concept formation and guided practice.
- 复习课: use knowledge map, error diagnosis, transfer tasks, and spaced retrieval.
- 习题课: group by problem type, highlight methods and grading points.
- 实验课: emphasize safety, variables, records, and evidence.
- 公开课: sharpen the main problem, student thinking visibility, and time control.
- 线上/混合课: add interaction checkpoints, asynchronous materials, and concise instructions.
