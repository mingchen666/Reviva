# Teaching Document Templates

Use these templates when the user asks for formal teacher documents or Office files.

## Standard Lesson Plan DOCX

Recommended sections:

1. 基本信息
2. 教材与内容分析
3. 学情分析
4. 教学目标
5. 教学重点与难点
6. 教学方法与学习方式
7. 教学准备
8. 教学过程表
   - 环节
   - 时间
   - 教师活动
   - 学生活动
   - 设计意图
   - 评价方式
9. 板书设计
10. 作业设计
11. 教学反思

## Unit Design

Use for 单元整体教学设计:

- unit theme and curriculum basis;
- big ideas / essential questions;
- learner analysis;
- unit objectives and competency goals;
- lesson sequence;
- unit assessment task;
- resources and differentiation;
- homework/project plan.

## Speaking Lesson / 说课稿

Use for 说课、教研展示、公开课说明:

1. 说教材
2. 说学情
3. 说目标
4. 说重难点
5. 说教法学法
6. 说教学过程
7. 说板书与评价
8. 说反思与改进

Keep the language oral and persuasive. Do not turn it into a plain lesson plan.

## Complete Preparation Package

When the user asks for 完整备课包, generate or coordinate:

- DOCX: formal lesson plan;
- PPTX or HTML slides: courseware;
- DOCX: student worksheet / learning sheet;
- DOCX: teacher answer key and explanations;
- XLSX or DOCX: assessment rubric / observation table;
- Markdown: short delivery summary.

## File Output Notes

- Use tables for lesson process and rubrics; they convert better to DOCX/XLSX.
- Keep student handouts clean: no teacher-only answer notes unless making a teacher edition.
- For PPTX, provide slide titles, learning flow, visual ideas, speaker notes, and assessment checkpoints before generation.
