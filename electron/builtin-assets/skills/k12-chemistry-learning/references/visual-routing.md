# 化学可视化路由

## 三层对应

化学可视化优先建立“宏观现象 -> 微观粒子 -> 符号表达”的对应。先用文字、方程和表格确认事实，再选择图或页面；可视化不能掩盖化学式、条件或现象的不确定性。

| 学习障碍 | 首选表示 | 可调用 Skill | 必须保留 |
| --- | --- | --- | --- |
| 周期趋势、原子结构和电子层 | 趋势图、层级图或对照卡 | `concept-visualization-generator`、`learning-visualization-skill` | 族/周期、比较方向、适用范围和术语定义 |
| 化学键、分子构型和极性 | 粒子模型、几何构型或标注对照 | `concept-visualization-generator` | 原子标签、空间关系、简化模型声明 |
| 方程式配平、原子守恒和计量 | 粒子计数图、守恒表或比例卡 | `concept-visualization-generator` | 化学式下标、系数、原子计数、单位 |
| 溶液、浓度、滴定和曲线 | 量筒/滴定装置示意、数据表或曲线 | `learning-visualization-skill` | 量、单位、终点定义、数据来源和误差 |
| 装置、现象与解释对应 | 装置标注、流程图和三层对照表 | `concept-visualization-generator` | 可观察现象、条件、推断与安全边界 |
| 已知反应的断键成键或电子转移 | 微观反应动画 | `edu-chem-reaction` | 已校验的物种、原子映射、条件和守恒 |

## 反应限制

只有注册反应或能通过 `edu-chem-reaction` kernel 校验的反应才能生成微观动画。未知产物、模糊方程、未经核验的复杂机理和危险条件改用文字说明或请求补充；不通过搜索摘要直接生成反应动画。

## 输入与降级

生成前确认年级/教材（仅在范围确实相关时）、反应式、条件、现象、单位和教学目标。图片中的下标、箭头、装置或颜色看不清时先回显待确认内容。依赖或命令未获审批时，输出 KaTeX、守恒表、ASCII 草图或安全的概念说明，不声称文件已生成。

## 批量题目路由

`exam2knowledge` 只对用户提供的错题、试卷或可核验公开样题做考点和反应类型归纳。把样本证据、教材范围和不确定项分开，不生成地区高频、押题或实验结论。
