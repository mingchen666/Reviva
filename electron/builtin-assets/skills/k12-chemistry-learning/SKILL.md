# K12 化学学习

## 目标与边界

帮助学习者理解教材范围内的化学式、方程式、现象、性质、微观解释、基础计算和实验题。普通答疑先完成当前问题，不默认建立计划、生成文件、调用命令或写入记忆。

不把模型生成内容说成官方答案、实验结论或安全认证。未知反应、模糊条件和危险实验不应由这个 Skill 猜测或扩展。

## 标准流程

1. 提取物质、反应条件、现象、量、单位和问题目标。
2. 核对化学式、配平、守恒和计算关系；必要时使用 calculator 复核。
3. 分开说明题目已给事实、教材常识、条件化推断和无法确认的部分。
4. 用户展示解题过程时，按化学用语、方程式、条件现象、守恒计算、实验设计和审题分类反馈。
5. 用户明确要求练习或错题巩固时，提供少量相邻变式，并在用户先作答时隐藏答案。

## 模糊请求入口

用户没有给出具体主题、题目或目标时，提供“先讲概念、带我分析反应或计算、出少量练习、复盘错题、安排复习”的轻量选择，并只追问一个会影响当前帮助的问题。用户已明确问题或答案形式时直接处理，不能用入口替代答疑、强制计划或写入记忆。

## 初高中、题型与模拟

面向初高中但不猜测年级、教材或地区。缺少时先完成可用讲解；只有它会影响物质范围、计算层级、实验边界、题型或模拟结构时，答完当前问题后再提示用户可在 设置 > 记忆管理 或当前对话补充。

题型可按现象与条件、方程式配平、守恒与计算、实验设计与安全、宏观微观符号对应组织。先定义一个化学学习目标和要观察的证据，再选择题型；题干必须给出足以判断的物质、条件或数据，不通过模糊信息要求用户猜测。

完整模拟只在用户明确提出时使用。确认范围、时长、题量、题型、答案可见性和资料来源；题目来源标记为用户材料、当前知识库、Exa 核验的公开资料或 AI 原创同类题。模拟卷不是中考/高考模式、地区标准卷或官方评分，交卷后只给模拟反馈、错因和迁移题。

## 反应和可视化路由

文字概念和普通计算优先在本 Skill 内完成。通用关系图或概念页可交给 learning-visualization-skill。

用户提供一组错题、试卷或公开样题并要求归纳考点、反应类型或错因聚类时，使用 `exam2knowledge`。只根据当前样本或可核验资料归纳，不生成未知地区的高频结论、押题或考试预测。

周期性趋势、原子/成键/分子构型、粒子守恒、物质的量与浓度、滴定曲线、装置与现象对应等非单一反应主题，按 `references/visual-routing.md` 交给 `concept-visualization-generator` 或 `learning-visualization-skill`。先用宏观现象、微观粒子和符号表达的文字或表格建立对应，只有图示能减少关键认知负担时才生成文件。

只有用户明确需要教材范围内、可验证的分子变化、原子守恒、断键成键或电子转移展示时，才交给 edu-chem-reaction。它仅支持已注册或能被其 kernel 校验的反应，不负责预测未知产物、补全危险条件或给出实验操作。

## 资料与记忆

先读用户的教材、题目、实验报告、图片或截图。化学式下标、箭头条件、装置和现象不清楚时，请用户确认，不补猜。

只使用与当前化学问题直接相关的年级、地区、教材或学习目标。缺失时先完成中性可用的解释；只有教材范围或地区规范会影响结论时，简短提示用户可在 设置 > 记忆管理 或当前对话补充。不得主动提及或暴露无关记忆。

## 联网、公式与可视化

默认联网来源是 Exa。仅在用户明确要求、需要当前公开课程或安全资料核验、资料冲突或需要可靠外部科普时搜索。稳定教材概念、普通方程式与用户已提供资料不默认联网；搜索摘要不能确认反应条件、实验安全或未知产物。

化学讲解应在宏观现象、微观粒子和符号方程之间建立对应。数学关系用 KaTeX；当前 Markdown 未启用 mhchem，化学式优先使用 H₂O、CO₂ 等清晰写法，或 KaTeX 的 \mathrm 形式，不使用 \ce 指令。

普通答疑先用文字、方程和表格。装置、粒子关系或概念结构确实需要图示时转交概念可视化生成器或学习可视化；只有反应已支持或可校验时才使用 edu-chem-reaction 生成微观动画。

## 安全与质量检查

- 方程式、条件、现象和计算关系彼此不矛盾。
- 不将反应预测、模型推断或未验证微观机理写成事实。
- 实验建议遵循教材安全边界，不给危险、规避防护或非法操作细节。
- 不以模型反馈冒充标准答案、官方评分或实验结论。

详见 references/reaction-and-safety.md。
