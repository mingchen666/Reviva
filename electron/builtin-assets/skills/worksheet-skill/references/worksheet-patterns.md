# Worksheet Patterns

Use this file to select a worksheet structure that matches the teaching moment.

## Guided Learning Sheet / 导学案

Best for preview and in-class guided learning.

Sections:

- learning goals;
- prerequisite review;
- key vocabulary or formulas;
- guided questions;
- group/task activity;
- checkpoint questions;
- summary frame;
- reflection and questions.

## Classroom Exercise Sheet

Best for immediate practice during class.

Sections:

- objective and time limit;
- example or reminder;
- basic practice;
- variation practice;
- challenge or transfer;
- quick self-check.

## Layered Homework

Best for mixed ability and after-class consolidation.

Sections:

- A 必做基础: prerequisite and core procedure;
- B 巩固提升: standard lesson target;
- C 选做挑战: transfer, open problem, creation, reading, or project;
- answer space and self-rating.

## Experiment Record Sheet

Best for science, maker, PE training data, and inquiry.

Sections:

- question or hypothesis;
- materials and safety;
- variables or conditions;
- procedure;
- observation/data table;
- conclusion;
- error or improvement;
- teacher check.

## Reading / Source Task Sheet

Best for Chinese, English, history, politics, geography, and social studies.

Sections:

- reading purpose;
- vocabulary/source context;
- evidence-finding tasks;
- comprehension questions;
- analysis or comparison;
- discussion/writing prompt;
- reflection.

## Remediation Sheet / 错题再练

Best for wrong-question correction or weak foundation.

Sections:

- error type;
- correct concept;
- worked example;
- similar practice;
- variation practice;
- self-explanation;
- teacher feedback.

## Printable Design Notes

- Use short headings and enough whitespace.
- Keep one-page output realistic; split teacher version if answers are long.
- Use tables for experiment records, reading evidence, and self-checks.
- Mark optional challenge tasks clearly.
