# Differentiation for Worksheets

Use this when students have different readiness levels, learning needs, or when the user asks for 分层、培优补差、基础薄弱、提高班、特殊支持.

## Tiering Patterns

### Three-Level Practice

- A 基础巩固: vocabulary, formulas, direct examples, one-step tasks.
- B 能力提升: standard application, multi-step tasks, explanation.
- C 拓展挑战: transfer, proof, open question, creation, project, real-world case.

### Remediation-Core-Extension

- Remediation: prerequisite review, worked example, guided steps.
- Core: target objective, independent practice.
- Extension: unfamiliar situation, reasoning, design, comparison.

### Choice Board

Use 4-6 options when motivation and autonomy matter:

- explain;
- draw/model;
- solve;
- compare;
- create;
- teach a peer.

## Supports

- vocabulary bank;
- formula or method card;
- sentence starters;
- step checklist;
- diagram scaffold;
- partially completed table;
- example and non-example;
- hint ladder from mild to explicit.

## Grade Band Adjustments

- 小学低段: fewer tasks, larger space, pictures, concrete examples, oral/visual response.
- 小学高段: short guided questions, example-first, optional challenge.
- 初中: misconception checks, variation practice, peer explanation.
- 高中: proof/reasoning, transfer, exam-style grading points, error analysis.
- 职教/培训: workplace case, task product, checklist, rubric.

## Teacher Version Additions

For each tier, include:

- target students;
- estimated time;
- expected answer;
- common mistake;
- feedback sentence;
- next-step suggestion.
