# Source Quality Guide

Use this guide to judge whether a source is suitable for teacher-facing materials.

## Source Priority

1. User-provided materials and school templates.
2. Official education authorities, curriculum bodies, examination boards.
3. School, university, museum, library, academic society, textbook publisher.
4. Reputable educational organizations and public media.
5. Teacher blogs, forums, commercial resource sites, and AI-generated pages only as inspiration.

## Reliability Checks

- Authority: who published it?
- Date: is it current enough for the topic?
- Scope: does it match the user’s region, grade, subject, and curriculum?
- Evidence: does it support the exact claim?
- Stability: is the link likely to remain accessible?
- Rights: can it be reused, quoted, or transformed safely?

## Output Labels

Use clear labels:

- 官方依据: policy, curriculum, examination, school/template requirement.
- 权威资料: university, museum, library, academic or public institution.
- 教学素材: usable classroom inspiration, not official basis.
- 待核实: plausible but missing date, author, or official status.

## Fallback Strategy

If a site is blocked or inaccessible:

- try another official domain or organization;
- use user files and knowledge base first;
- mark inaccessible source as not used;
- do not invent details from inaccessible pages;
- ask the teacher for local curriculum files when official regional information matters.

## Citation Notes

For each source, capture:

- title;
- organization/author;
- publication/update date when visible;
- URL or file path;
- how it will be used;
- reliability/copyright caution.
