# Curriculum and Policy Research

Use this file when the user asks for 课标、课程标准、教材版本、考试要求、政策文件、官方依据、地区要求.

## Required Context

Ask or infer carefully:

- country/region/province/city;
- education stage and grade;
- subject;
- textbook version or publisher;
- exam type if relevant;
- whether the user needs exact wording or only teaching alignment.

## Search Strategy

Use precise queries:

- `[地区] [学科] 课程标准 官方`
- `[考试名称] [学科] 考试说明 官方`
- `[教材版本] [年级] [课题] 教材 目录`
- `[教育部门] [文件名] PDF`

Prefer official pages and PDFs. If exact policy wording is needed, do not rely on third-party summaries unless clearly marked as secondary.

## Curriculum Alignment Output

Use this structure:

```markdown
## 课标/政策依据
- 来源：
- 适用范围：
- 与本课相关点：
- 不能确认的点：

## 教学转化
- 目标表述：
- 活动建议：
- 评价证据：
```

## Cautions

- Standards and policies differ by region and year.
- Textbook editions differ; do not invent unit, page, or lesson numbers.
- Exam requirements can change; mark the date of retrieval or source date.
- If the user needs school-specific interpretation, ask for the school file/template.
