# Materials Curation

Use this file when selecting teaching examples, cases, media, public lesson inspiration, or current-event materials.

## Material Types

- Hook: story, image, question, short video idea, data point.
- Concept explanation: analogy, diagram idea, historical background, model.
- Activity: case discussion, experiment, simulation, debate, project.
- Practice: dataset, text excerpt, graph, problem context.
- Extension: reading, real-world application, career case.

## Selection Criteria

- Matches grade and cognitive level.
- Serves a learning objective.
- Is short enough for classroom time.
- Avoids unnecessary controversy or privacy risk.
- Can be transformed into student task or teacher explanation.
- Has clear source and usage caution.

## Grade Fit

- 小学: concrete, visual, familiar life context, short text.
- 初中: observable conflict, simple data, relatable cases, structured reasoning.
- 高中: abstract model, data interpretation, evidence debate, transfer.
- 大学/职教/培训: professional scenario, project case, authentic task.

## Copyright and Safety

- Prefer public-domain, official, Creative Commons, or user-provided materials.
- Summarize and transform long texts; do not copy large passages.
- Avoid identifiable student/person data unless user explicitly provides internal-use material.
- For experiments, include safety and feasibility constraints.

## Curation Output

For each material, include:

- what it is;
- why it helps;
- where to use it in class;
- how to adapt by grade;
- source and caution.
