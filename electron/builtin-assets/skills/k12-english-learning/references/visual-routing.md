# 英语学习可视化路由

## 选择顺序

英语学习的可视化以证据和结构为主，不以装饰为目的。先用行内标注、表格或前后文本对照；只有结构或复习需要明显受益时，才生成 HTML 页面。

| 学习障碍 | 首选表示 | 可调用 Skill | 必须保留 |
| --- | --- | --- | --- |
| 句子成分、从句和时态结构 | 句法树、颜色标注或层级卡 | `learning-visualization-skill` | 原句、成分边界、时态/语气和改动理由 |
| 阅读主旨、证据链和选项辨析 | 原文高亮、证据表或论证图 | `learning-visualization-skill` | 原文句子、段落位置、事实与推断边界 |
| 段落结构和写作连贯性 | 段落骨架、论证流程、前后对照 | `learning-visualization-skill` | 用户原意、任务要求和修改标记 |
| 词汇搭配、同义反义和语境 | 关系图、语境卡或对比表 | `learning-visualization-skill` | 词性、语境义、搭配和例句来源 |

## 输入与交付

处理阅读、作文或翻译资料时先读取原文；图示中的每个证据都能回指原文位置。练习页面须隐藏答案直到用户作答，提供重置/查看提示，并说明这是学习辅助材料，不是官方评分。

## 降级规则

- 普通词汇、语法和阅读问题直接文字回答，不自动创建文件。
- 原文、图片或手写内容不清时请求补充，不用外部搜索替代缺失的题干证据。
- 用户没有明确想要页面时，用标注句、对照表或 Markdown 关系图；不执行命令。
- 外部作者、课程或时效事实才按需使用 Exa，并标注来源；搜索结果不能伪造阅读原文。
