# Native PPTX Layout Recipes

Use these recipes with the OfficeCLI PPTX reference. Coordinates should follow the standard 16:9 deck size described in `officecli-skills/references/pptx.md`.

## L1 Cover

Use for the first slide.

- Background: solid or restrained gradient.
- Elements: title, subtitle, author/team/course, date/context.
- Visual: one motif element, brand band, or key image.
- Avoid title-only covers.

## L2 Section Divider

Use between modules or major arguments.

- Large section number or module label.
- Short section title.
- One-sentence orientation.
- Minimal body content.

## L3 Teaching Concept

Use for definitions and core ideas.

- Left: concise definition or principle.
- Right: diagram, analogy, formula, or example.
- Bottom: "remember this" takeaway.

## L4 Worked Example

Use for math, coding, language, science, or process examples.

- Top: problem statement.
- Middle: 3-5 numbered steps.
- Right or bottom: final answer/result.
- Use arrows/connectors instead of bullets when the sequence matters.

## L5 Comparison Matrix

Use for before/after, A/B, competitors, options, methods.

- 2-4 columns maximum.
- Rows are criteria, not paragraph buckets.
- Highlight the decision-driving row.

## L6 KPI Snapshot

Use for office reports and executive decks.

- 3 or 4 large metrics.
- Each metric has label, period, and delta/status.
- Add a short interpretation, not just numbers.

## L7 Timeline / Roadmap

Use for plans, project progress, study plans, and course schedule.

- 4-6 stages maximum.
- Each stage includes date/phase, owner or outcome, and status.
- Use connectors with consistent direction.

## L8 Risk / Issue Board

Use for project reviews and decision meetings.

- Columns: issue, impact, owner, next action.
- Color is status, not decoration.
- Keep rows short enough for projection.

## L9 Research Evidence

Use for research briefs and literature/competitor summaries.

- Left: claim or finding.
- Right: evidence, source note, chart, or quote.
- Bottom: implication.
- Never invent source details.

## L10 Practice / Checkpoint

Use for learning decks.

- Prompt/question.
- 2-4 options or a short task.
- Answer/reveal can be placed in speaker notes or a following slide.
- Do not crowd with explanation.

## L11 Closing / Action

Use for last slide.

- Recap 3 points or decisions.
- Next actions with owner/date when office-related.
- Learning next step when education-related.

## Layout Rules

- Do not repeat the same layout on three adjacent slides.
- Use cards only when they contain repeated items; do not put a page section inside a decorative card.
- Avoid colored left-border cards and decorative title underlines.
- If a slide needs more than 6 bullets, split it.
- If text must shrink below 18pt, split or simplify.
