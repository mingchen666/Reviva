# Template: Custom Creative

Use only when stable templates do not fit, or when the user explicitly asks for a more creative or distinctive deck.

## Process

1. Identify the audience and purpose.
2. Choose the closest stable template as a base.
3. Pick a theme and one visual motif.
4. Combine 5-8 layouts from `layouts.md`.
5. Write a title-only storyboard first.
6. Create the PPTX with editable shapes, charts, text, and notes.
7. Run QA strictly.

## Allowed Creative Moves

- Bolder cover or divider slides.
- Asymmetric layouts.
- More distinctive motif.
- Custom icon/shape system.
- Stronger image treatment when user provides images.

## Not Allowed

- Shrinking text to fit.
- Using many unrelated colors.
- Building unreadable decorative slides.
- Putting key content only in animation.
- Creating a file that is hard to edit in PowerPoint/WPS.

## Theme

Default: Creative Custom, adapted to the user request.
