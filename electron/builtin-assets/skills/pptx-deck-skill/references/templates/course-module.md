# Template: Course Module

Use for lesson decks, classroom courseware, and structured teaching.

## Typical Arc

1. Cover: course/module title and learning context.
2. Learning objectives: 3-4 outcomes.
3. Prerequisite recall: what students should already know.
4. Concept map: where this module fits.
5. Core concept 1: definition + visual.
6. Worked example 1.
7. Core concept 2: contrast or mechanism.
8. Practice checkpoint.
9. Common misconception.
10. Summary: 3 key takeaways.
11. Next step / homework / reading.

## Recommended Layouts

L1, L3, L4, L5, L10, L11.

## Theme

Default: Education Clear.

## Notes

Speaker notes should explain how to teach the point, not repeat the slide verbatim.
