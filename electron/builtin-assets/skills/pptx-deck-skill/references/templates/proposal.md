# Template: Proposal

Use for plans, solution proposals, implementation proposals, and internal approvals.

## Typical Arc

1. Cover: proposal name.
2. Problem / objective.
3. Current constraints.
4. Recommended solution.
5. Implementation roadmap.
6. Resource and cost outline.
7. Risks and mitigations.
8. Success metrics.
9. Decision request.

## Recommended Layouts

L1, L3, L5, L7, L8, L11.

## Theme

Default: Office Focus or Executive Signal.
