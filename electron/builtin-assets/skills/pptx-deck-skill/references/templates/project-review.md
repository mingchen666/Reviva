# Template: Project Review

Use for project updates, milestone reviews, retrospectives, and delivery reviews.

## Typical Arc

1. Cover: project and review date.
2. Current status and target.
3. Timeline / milestones.
4. Scope delivered.
5. Quality or metric evidence.
6. Risks and blockers.
7. Tradeoffs / decisions.
8. Next phase plan.
9. Owner-action table.
