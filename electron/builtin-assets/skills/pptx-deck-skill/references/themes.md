# PPTX Theme Tokens

These are starting points for native PPTX themes. User-provided brand colors, school colors, or existing template styles override them.

## Creative Custom

Use only when the user asks for a more distinctive style or no stable scene fits.

- Pick one dominant color, one supporting color, one accent.
- Keep body text on light fills unless the slide is a deliberate cover/divider.
- Never use more than two font families.
- Carry one motif across the whole deck: numbered circles, side rail, chapter tabs, or geometric blocks.
- Use high contrast for projection.

## Theme Discipline

- Do not mix several palettes in the same deck.
- Do not use a one-note palette where every element is the same hue.
- Do not rely on Office defaults for text size or font.
- Do not use gradients as a substitute for layout.
- Dark backgrounds are acceptable for covers/dividers, but content slides usually read better on light backgrounds.
