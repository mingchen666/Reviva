# Scenario Playbooks

Use these quick patterns when the teacher describes a practical classroom problem.

## 基础薄弱

- Add 3-minute prerequisite activation.
- Give one worked example and one half-completed example.
- Use A/B/C tasks: A must complete, B core objective, C optional.
- Teacher checks first step, not final answer only.
- Exit ticket asks one core idea and one confusion.

## 两极分化

- Set common core task for all.
- Add extension task that requires explanation, transfer, or creation.
- Use peer explanation after individual attempt.
- Avoid making advanced students only "helpers"; give them real challenge.

## 注意力不集中

- Shorten teacher talk into 5-8 minute chunks.
- Use visible timer and product requirement.
- Add response mode: card, poll, mini whiteboard, one-sentence answer.
- Give transition signal and reset routine.

## 大班教学

- Use pair checks and group reporters.
- Sample student work instead of checking all.
- Use color cards or quick survey for understanding.
- Prepare one common misconception explanation.

## 公开课/赛课

- Prepare accessible first question.
- Prepare backup prompts if students are silent.
- Mark must-do and optional sections.
- Keep one high-quality activity instead of many shallow activities.
- Use board/slide evidence to show student thinking.

## 实验/活动安全

- State safety rule before material distribution.
- Assign materials manager.
- Demonstrate stop signal.
- Use observation table to keep students focused.
- Prepare emergency stop and cleanup procedure.

## 线上课堂

- Start with poll or short response.
- Keep tasks in small chunks.
- Require visible product: screenshot, shared note, answer form.
- Use backup async task if live interaction fails.
