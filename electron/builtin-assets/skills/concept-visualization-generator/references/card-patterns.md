# Concept Card Patterns

Concept cards are study objects. They should support understanding and later retrieval, not just summarize.

## Core Pattern

```markdown
# Concept

Learning goal:

One sentence:

Intuition:

Definition / formula / mechanism:

Visual anchor:

Worked example:

Misconception:

Self-check:

Related concepts:

Next step:
```

## Good Card Properties

- Tests one idea.
- Opens with a simple sentence.
- Uses one visual anchor.
- Includes one misconception and correction.
- Includes at least one retrieval prompt.
- Links to adjacent concepts.
- Avoids long paragraphs.

## Retrieval Check Types

### Recall

Ask the learner to produce the core idea from memory.

Example:

> 不看上面的定义，用一句话说出导数描述的是什么。

### Misconception

Ask the learner to identify or correct a tempting wrong idea.

Example:

> 判断：函数值越大，导数一定越大。这个说法为什么错？

### Transfer

Ask the learner to use the concept in a nearby but new situation.

Example:

> 如果图像在某点向下走得很快，这一点的导数符号和大小大概怎样？

### Self-Explanation

Ask the learner to explain a step or relation.

Example:

> 为什么割线两点越来越近时，会逼近切线的斜率？

## Card Set Pattern

For source-grounded material, make multiple cards:

- one overview card;
- one card per major concept;
- one misconception card;
- one practice card;
- one "what to learn next" card.

Do not make every sentence into a card. Cards should correspond to meaningful knowledge units.

## Difficulty Labels

Use simple labels:

- `foundation`: must know before learning the topic;
- `core`: central concept;
- `application`: used in problems;
- `misconception`: common trap;
- `extension`: useful next idea.
