# 示例：批量刷题

## 出题阶段

- 10道资料分析。
- 答案隐藏。
- 题目按两篇材料分组。
- 每题显示来源标签，不显示正确答案暗示。

## 用户提交

```text
1A 2C 3B 4D 5A
6C? 7B 8D 9A 10C
总用时24分钟
```

## 批改摘要

```markdown
## 本组结果
- 正确率：8/10
- 用时：24分钟（用户报告）
- 题源：用户题库8题，AI自编同类题2题

## 主要问题
- 两道错题都属于基期量计算，但错因不同：第3题列式错误，第8题计算错误。
- 第6题虽做对但把握度低，需要补一题同类验证。

## 下一组
5道基期量与增长量混合题，目标是在8分钟内完成并保持80%以上正确率。
```
