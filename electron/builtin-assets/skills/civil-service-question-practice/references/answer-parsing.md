# 用户答案解析

## 支持格式

```text
1A 2C 3D
1.A
2.C
第1题选A，因为……
1A? 2C确定
```

## 解析原则

1. 先建立当前题组的合法题号集合。
2. 统一大小写和中文/英文标点。
3. 保留用户的把握度、理由和用时信息。
4. 重复题号时请求确认最后答案。
5. 题号缺失或错位时不直接批改。
6. 用户只提交部分答案时，只批改已提交部分，不泄露其他答案。

## 主观题

主观题必须按题号或明确分隔提交。无法判断哪段对应哪题时先确认。

## 把握度

推荐内部记录：

| 标记 | 含义 |
|---|---|
| 确定 | 高把握 |
| `?`、犹豫 | 低把握 |
| 未标记 | 未记录 |

“蒙对但低把握”不能等同于稳定掌握；“改错答案”应标记为犹豫后改错，而不是知识缺口。
