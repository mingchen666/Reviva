# 公考刷题错因分类

| 错因 | 识别证据 | 对应训练 |
|---|---|---|
| 知识/公式缺口 | 不知道概念、公式或固定关系 | 回到方法学习，再做基础题 |
| 题型识别错误 | 用错题型方法 | 练识别标志和少量分类题 |
| 方法选择不当 | 能做但步骤过长或方法不适用 | 对比更优方法，限步训练 |
| 材料定位错误 | 找错数据、主体、时间或范围 | 定位专项和关键词标记 |
| 审题遗漏 | 忽略“最不、不能、同比、以上”等限定 | 慢读题干和限定词复盘 |
| 计算错误 | 列式正确但运算错 | 速算、估算和验算训练 |
| 选项比较错误 | 推理正确但排除/比较失误 | 选项差异和陷阱训练 |
| 时间取舍问题 | 卡题过久、顺序不合理 | 模块限时和跳题规则 |
| 犹豫后改错 | 初选正确后无依据改错 | 记录改答案触发条件 |
| 偶发操作错误 | 涂错、题号错位、漏答 | 答题卡和检查流程 |

## 归因规则

- 错因必须对应用户过程、答案或用时证据。
- 不知道用户过程时可以给候选错因并追问。
- 不把所有错误都写成“粗心”。
- 同一题可以有主错因和次错因。
- 下一组训练只针对高频、可复现的主错因。
- “犹豫后改错”必须有初选、改选或用户复盘证据；不能依据最终错误倒推。
- 正误与把握度可联合记录，但把握度不是能力分数，高信心错误应优先复核概念或方法。
