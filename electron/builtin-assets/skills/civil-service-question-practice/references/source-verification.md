# 题源核验规则

## 题源等级

| 标签 | 条件 |
|---|---|
| 用户题库 | 来自用户本轮文件或粘贴内容 |
| 知识库 | 来自用户选择的云端知识库 |
| 公开真题·已核验 | 题干、选项、答案、年份、地区/卷型和URL基本完整 |
| 机构公开题 | 来自公开机构页面，保留机构名称与URL |
| AI自编同类题 | 模型根据考点生成，必须显式标注 |
| 来源待核验 | 题目或来源信息不完整，不能当真题 |

## 联网核验流程

1. Exa 找候选页面。
2. Firecrawl 读取完整题目、材料和解析。
3. Bing 补充或交叉验证。
4. 核对题干、选项、答案、年份、地区、科目和卷型。
5. 有冲突时独立解题并标记争议。

## 不得标记为已核验真题

- 只有搜索摘要。
- 缺选项或材料数据。
- 答案来自无法确认的转载。
- 多个来源答案冲突且未解决。
- 只凭题目风格猜测年份或地区。

## 用户文件核验

- 题目和答案跨页时检查题号对应。
- 扫描识别不清时标记待核验。
- 文件没有答案时写“模型复核答案”。
- 不编造原文件页码和出处。

## 版权边界

不批量复制付费题库、受限讲义或整套商业内容。公开网页按当前训练需要适量引用并保留来源。用户合法提供的资料可用于个人抽题与复习。
