# Assessment Patterns

Use this file to choose assessment forms that fit classroom timing and evidence needs.

## Formative Assessment

Purpose: identify student understanding during learning and adjust instruction.

Patterns:

- cold start diagnostic: 2-3 prerequisite questions before teaching;
- hinge question: one key multiple-choice/concept question before moving on;
- mini whiteboard/card response: fast whole-class check;
- think-pair-share evidence: collect reasoning, not only answer;
- exit ticket: final evidence and next-step grouping.

## Hinge Question Design

A hinge question should:

- target the key concept;
- be answerable in 1-2 minutes;
- include distractors based on common misconceptions;
- let the teacher decide whether to continue, reteach, or group support.

## Diagnostic Feedback

Use this table:

| Evidence | Likely cause | Teacher response | Student next step |
| --- | --- | --- | --- |
| wrong procedure | prerequisite gap | quick worked example | redo one similar item |
| correct answer, weak reason | shallow understanding | ask evidence question | explain to peer |
| slow completion | cognitive load high | reduce steps/scaffold | complete checklist |
| strong completion | ready for extension | challenge task | create new example |

## Homework Grading

Include:

- total points or qualitative levels;
- required method/steps;
- answer accuracy;
- explanation/evidence quality;
- neatness only when it matters to readability;
- common errors and feedback.

Avoid grading hidden effort unless there is observable evidence.

## Teaching Reflection Evidence

Good reflection uses:

- student work samples;
- exit ticket distribution;
- classroom observation notes;
- misconception patterns;
- activity timing;
- student questions;
- homework results.

Reflection prompts:

- Which objective was achieved? What evidence shows it?
- Which objective was weak? What misconception appeared?
- Which activity produced the best thinking evidence?
- What should be adjusted next time: sequence, question, material, time, support?
