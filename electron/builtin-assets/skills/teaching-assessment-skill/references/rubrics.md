# Rubrics

Use this file when designing 评价量规、评分表、表现性任务评价、项目评价、作文/演讲/实验/小组合作评价.

## Rubric Design Rules

- Use 3-5 criteria. More criteria makes classroom use slow.
- Use 3 or 4 performance levels.
- Criteria must be observable.
- Level descriptors should describe quality, not only "excellent/good/average".
- Align criteria to the product or performance task.
- Include teacher feedback notes when used for grading.

## Common Level Names

4-level:

- 优秀
- 达标
- 发展中
- 需支持

3-level:

- 完成良好
- 基本完成
- 需要改进

Customize labels and criteria by subject.

## Task-Specific Criteria

### Writing

- content and focus;
- structure;
- evidence/details;
- language expression;
- revision.

### Presentation

- content accuracy;
- organization;
- evidence/visual support;
- delivery;
- response to questions.

### Experiment

- hypothesis and variable control;
- procedure and safety;
- data recording;
- analysis;
- conclusion and error reflection.

### Project / Product

- goal fit;
- design quality;
- process evidence;
- collaboration;
- final product and reflection.

### Group Work

Separate:

- group product quality;
- individual contribution;
- communication;
- role responsibility;
- peer feedback.

## Feedback Sentence Bank

- "你的结论基本正确，下一步需要补充支持结论的证据。"
- "过程步骤完整，但关键概念解释还不够清楚。"
- "你能找到问题，但需要说明为什么这个方法有效。"
- "作品完成度较高，建议进一步比较另一种方案的优缺点。"
- "请根据量规中的第 X 项，补充一个例子或数据。"
