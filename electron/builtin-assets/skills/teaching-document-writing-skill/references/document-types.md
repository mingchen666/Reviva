# Teaching Document Types

Use this file to pick a structure for common teacher documents.

## 说课稿

1. 说教材
2. 说学情
3. 说教学目标
4. 说重点难点
5. 说教法学法
6. 说教学过程
7. 说板书与评价
8. 说反思与改进

Tone: oral, logical, persuasive. Avoid copying the full lesson plan.

## 教学反思

1. 课堂目标与实际达成
2. 学生表现证据
3. 有效做法
4. 暴露问题
5. 原因分析
6. 后续调整

Tone: honest, specific, improvement-oriented.

## 听课记录 / 评课稿

1. 基本信息
2. 课堂流程记录
3. 亮点
4. 学生学习证据
5. 可改进点
6. 建议

Tone: respectful and evidence-based. Avoid personal judgment without classroom evidence.

## 教研总结

1. 工作背景
2. 主要活动
3. 形成成果
4. 典型案例
5. 问题与改进
6. 下一阶段计划

Use tables when listing meetings,公开课,磨课, training, or成果.

## 教学案例

1. 案例背景
2. 问题情境
3. 设计思路
4. 实施过程
5. 学生表现
6. 效果分析
7. 反思启示

## 培训方案

1. 培训主题
2. 培训对象
3. 培训目标
4. 时间地点
5. 课程安排
6. 活动方式
7. 资料与设备
8. 评价与反馈

## 家校沟通 / 通知

1. 简短问候
2. 事项说明
3. 具体要求
4. 时间节点
5. 联系方式 or 反馈方式

Tone: warm, clear, non-blaming. Avoid exposing individual student privacy.
