# Style and Evidence Guide

Use this file when polishing education documents.

## Evidence Types

- lesson objective and classroom activity;
- student work or response;
- quiz/exit ticket result;
- observation notes;
- meeting record;
- training feedback;
- project/product evidence;
- user-provided numbers or examples.

If evidence is missing, write cautiously:

- "可从课堂表现、作业完成情况和学生反馈三个方面进一步收集证据。"
- "以下为基于现有材料的初稿，具体数据需教师补充。"

## Tone Choices

### Formal School Document

- concise headings;
- objective facts;
- concrete actions;
- limited adjectives;
- clear next steps.

### Teaching Reflection

- first-person or neutral voice is acceptable;
- name the problem directly;
- connect causes to classroom evidence;
- write actionable improvement.

### Parent-Facing Message

- warm and respectful;
- short paragraphs;
- clear action request;
- no blame or labels;
- protect student privacy.

### Public Lesson / Competition

- logical, polished, and evidence-focused;
- show learner-centered design;
- avoid exaggerated claims;
- include risk and adjustment plan.

## Phrases to Replace

| Weak phrase | Better replacement |
| --- | --- |
| 课堂效果较好 | 从学生回答、练习完成和出门条看，大多数学生能够... |
| 激发学生兴趣 | 通过真实情境/操作任务，让学生主动提出... |
| 提高学生能力 | 学生能够在...中完成...并说明理由 |
| 注重合作探究 | 小组内设置...角色，最终形成...成果 |
| 仍需改进 | 下一轮将调整...，增加...，并通过...检查效果 |

## Privacy and Accuracy

- Do not include student names unless user explicitly provides and requests it.
- Do not invent school names, policies, awards, official data, or teacher honors.
- If public publication is likely, anonymize sensitive examples.
