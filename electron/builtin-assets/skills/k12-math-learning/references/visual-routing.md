# 数学可视化路由

## 选择顺序

先判断用户要解决的学习障碍，再选择最小表达：

1. 文字、KaTeX、表格或手绘式标注足够时，不生成文件。
2. 需要看结构、对应关系或数据分布时，使用静态关系图或坐标图。
3. 需要拖动参数、逐步变换或反复自测时，才生成交互 HTML。

| 学习障碍 | 首选表示 | 可调用 Skill | 必须保留 |
| --- | --- | --- | --- |
| 函数图像、参数变化、定义域和值域 | 坐标图、参数滑块或逐步变换 | `math-explainer`、`learning-visualization-skill` | 坐标轴、单位/范围、参数值和结论依据 |
| 解析几何、轨迹、直线与圆锥曲线 | 带标注的坐标板 | `edu-analytic-geometry` | 题目给定点、方程、比例和坐标系方向 |
| 平面几何、立体几何、截面 | 静态几何图或可旋转模型 | `edu-solid-geometry`、`geometry-assistant` | 可见边、角、垂足、截面和已知关系 |
| 概率、统计、抽样和数据比较 | 表格、条形/折线/散点图 | `learning-visualization-skill` | 样本量、统计量定义、坐标刻度和不确定性 |
| 证明、分类讨论和条件依赖 | 关系图、分支图或步骤卡 | `learning-visualization-skill` | 每条边的依据，不把猜想画成定理 |

## 输入与交付

生成前确认主题、目标、已知条件、数据范围、用户要看懂还是要练习。练习模式先隐藏答案，并提供重置或逐步查看；图中每个变量都要在正文解释。图像或题干不清时先指出不确定标注，不补造点、线、数据或比例。

## 降级规则

- 缺少年级或教材时，先用不依赖教材的中性表示；只有范围会改变时才提示记忆管理。
- 缺少关键数据时，用符号表示并说明无法定量绘制，不能捏造示例数据冒充题目数据。
- 生成依赖或命令未获审批时，返回可读的 KaTeX/表格/ASCII 草图或说明所需输入，不宣称文件已生成。
