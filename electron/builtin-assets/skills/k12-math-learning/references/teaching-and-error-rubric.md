# 数学讲解与错因参考

## 讲解层次

1. 题目级：已知什么、求什么、哪一个条件决定方法。
2. 概念级：定义、性质、适用前提和一个反例。
3. 方法级：为什么选这个公式、辅助线或换元，关键转折在哪里。
4. 验证级：代回、范围、符号、单位、边界或反向推导。

根据用户要求选择足够的层次，不机械输出全部四层。

## 错因标签

- 条件遗漏：漏看范围、定义域、图形标记、已知关系或特殊情况。
- 概念混淆：把定义、性质、逆命题、充分必要条件或相似概念混在一起。
- 方法失配：公式、辅助线、坐标法、分类讨论或概率模型不适用。
- 推理断裂：结论没有依据，或从必要条件直接推出充分条件。
- 运算表达：符号、变形、计算、单位、格式或书写遗漏。

反馈格式应包含：错误位置、为什么错、如何改、一项最小检查或变式。不要把不确定的题干错误归因给用户。

## 练习规则

- 一次默认给一到三题，不堆题。
- 变式只改变一个关键维度，例如条件、图像、范围、问法或数值。
- 用户要求先做再批改时，隐藏答案。
- 用户已经能独立完成时，优先迁移而非重复原题。

## 辅导节奏与资料

- 先从当前题或用户过程定位一个关键卡点；资料充分时不要重复收集信息。
- 用户要完整答案时给完整答案，用户要提示时只推进当前一步。
- 讲解后的检查是按需的：仅在练习、误区或用户明确想确认时给一个短小的回忆或迁移问题。
- 用户资料、当前知识库、可核验公开资料和通用知识依次使用。稳定教材问题不需要联网；需要当前或官方资料时才用 Exa。
