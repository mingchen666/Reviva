# Research Sources For CS Course Learning

These sources are design references for this skill family. They are not runtime dependencies.

## 408 / Exam Structure

- 计算机考研杂货铺 408 大纲页: `http://www.csgraduates.com/study_methods/outline/2025/`
- 中国考研网 / 中国教育在线历史大纲转载 pages can help compare stable scope, but always verify current-year and target-school requirements through official/college sources.

Useful verified patterns:

- 408 commonly covers four subjects: data structures, computer organization, operating systems, and computer networks.
- Public outline snapshots commonly use the 45/45/35/25 score split and 150-point, 180-minute exam structure.
- Current-year syllabus, school adoption, and self-designed exam differences must be checked at runtime.

## Algorithm Visualization

- USFCA Data Structure Visualizations: `https://www.cs.usfca.edu/~galles/visualization/Algorithms.html`
- VisuAlgo: `https://visualgo.net/`

Useful design patterns:

- step-by-step execution;
- data structure + operation log + state table together;
- custom inputs and training/quiz modes;
- graph/tree/sorting/searching/DP coverage;
- exam-friendly hand simulation tables.

## Computer Organization Visualization

- Ripes: `https://github.com/mortbopet/ripes`
- QtMips: `https://github.com/cvut/qtmips/`
- ARM Graphical Micro-Architecture Simulator: `https://github.com/arm-education/Graphical-Micro-Architecture-Simulator`

Useful design patterns:

- visible register file, memory, instruction/data memory;
- highlighted data path and control path;
- cycle-by-cycle pipeline table;
- cache hit/miss and replacement visibility;
- assembly/instruction examples tied to hardware state.

## Operating System Visualization

- OS Algorithm Simulator: `https://phy-development.github.io/software/os-algorithm-simulator/index.html`
- OS visualizer projects commonly cover scheduling, deadlock, memory allocation, page replacement, disk scheduling, and synchronization.

Useful design patterns:

- user-provided datasets;
- Gantt charts and calculation tables;
- resource allocation / Banker's matrices;
- page frame tables and fault markers;
- test mode or quick-check after simulation.
