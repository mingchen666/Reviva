# 计算机网络

## 核心模块

- 体系结构：OSI、TCP/IP、封装与解封装、服务与协议。
- 数据链路层：成帧、差错检测、MAC、以太网、ARP、交换机。
- 网络层：IPv4/IPv6、子网划分、CIDR、ICMP、路由表、最长前缀匹配、NAT。
- 传输层：UDP、TCP、可靠传输、滑动窗口、流量控制、拥塞控制、连接管理。
- 应用层：DNS、HTTP/HTTPS、DHCP、SMTP/POP/IMAP 基础。
- 安全基础：TLS、证书、ACL/防火墙、VPN 概念。

## 推荐分支技能

- `computer-network-learning`：系统讲解和课程复习。
- `network-protocol-viz`：协议流程和数据包动画。
- `network-packet-lab`：抓包实验和实验报告。
- `network-exam-practice`：网络题训练、批改和错因诊断。

## 常见题型

- 子网划分、CIDR 汇总、最长前缀匹配。
- TCP 序号、确认号、窗口、拥塞窗口变化。
- DNS/HTTP/DHCP/TLS 协议流程。
- 交换机 MAC 表、路由表、防火墙规则判断。
- 抓包字段解释。

## 易错点

- 协议属于哪一层和解决的问题混淆。
- IP 地址、网络地址、广播地址、可用主机范围计算错误。
- TCP 连接管理和可靠传输机制混为一谈。
- 路由器转发和交换机转发依据混淆。
