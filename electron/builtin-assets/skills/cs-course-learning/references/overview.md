# 计算机专业课总览

## 适用场景

- 本科计算机专业课学习和期末复习。
- 408/考研计算机学科专业基础综合。
- 跨科综合题、错题归因、阶段计划和冲刺复习。

## 学习闭环

1. 建知识图谱：课程 -> 章节 -> 核心机制 -> 典型题型。
2. 查缺口：先补先修知识，再做综合题。
3. 练题型：按题型而不是只按章节刷题。
4. 复盘错因：概念混淆、公式/规则错误、过程漏步、计算粗心、审题错误。
5. 产出复习材料：速记页、错题卡、流程图、例题模板、模拟卷。

## 四科关系

- 数据结构：抽象数据类型、算法思想、复杂度，是很多综合题的基础。
- 组成原理：数据表示、指令、CPU、存储和 I/O，关注硬件如何执行程序。
- 操作系统：进程、内存、文件、I/O，关注资源管理和并发。
- 计算机网络：分层协议、转发、传输、应用协议，关注主机之间如何通信。

## 默认诊断问题

如果用户目标宽泛，询问：

1. 目标是期末、408、作业还是入门学习？
2. 当前科目和章节是什么？
3. 有没有课件、教材目录、错题或考试范围？
4. 距离考试还有多久，每天能投入多久？
