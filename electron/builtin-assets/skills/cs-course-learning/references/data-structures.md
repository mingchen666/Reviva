# 数据结构与算法

## 核心模块

- 复杂度分析：时间复杂度、空间复杂度、递归复杂度。
- 线性结构：顺序表、链表、栈、队列、串。
- 树：二叉树、线索二叉树、树/森林转换、哈夫曼树、BST、平衡树基础。
- 图：存储结构、遍历、最小生成树、最短路径、拓扑排序、关键路径。
- 查找：顺序查找、折半查找、哈希表、B/B+ 树基础。
- 排序：插入、交换、选择、归并、基数排序，稳定性和复杂度。

## 讲解原则

- 先讲数据结构解决什么操作需求，再讲存储结构。
- 算法题要给状态变化表或关键步骤，不只给最终答案。
- 复杂度题要说明变量含义、循环次数、递归式或主定理直觉。

## 常见题型

- 遍历序列还原树。
- 图算法手算过程。
- 排序过程、趟数、比较/交换次数、稳定性。
- 哈希冲突处理和平均查找长度。
- 算法设计与伪代码。

## 易错点

- 混淆逻辑结构和存储结构。
- 图的无向/有向、连通/强连通概念混淆。
- 二叉排序树删除、平衡调整细节漏步。
- 排序算法稳定性和空间复杂度记忆错误。
