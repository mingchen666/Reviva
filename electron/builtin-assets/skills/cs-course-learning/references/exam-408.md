# 408 / 计算机专业课考试复习

## 定位

408 通常指“计算机学科专业基础综合”，面向研究生入学考试中的计算机专业基础能力考查。稳定的复习对象是四门核心课：

- 数据结构；
- 计算机组成原理；
- 操作系统；
- 计算机网络。

常见公开资料会提到满分 150 分、考试时间 180 分钟、闭卷笔试等信息。但具体年份大纲、院校是否采用 408、自命题与统考差异、题型和范围变化，必须通过官方/院校/可靠公开来源在运行时核验，不要写死成最新事实。

公开大纲快照和多个复习资料中常见的结构是：

- 数据结构：45 分；
- 计算机组成原理：45 分；
- 操作系统：35 分；
- 计算机网络：25 分；
- 题型常见为单项选择题与综合应用题组合。

这些信息适合做默认复习规划假设；当用户要求“今年/某院校/某专业”的准确范围时，必须联网核验并标明来源。

## 资料核验优先级

当用户问“今年 408 考什么”“某学校是否考 408”“大纲变化”时，先核验来源：

1. 目标院校研究生招生网、学院官网、招生专业目录和考试大纲。
2. 中国研究生招生信息网及教育考试相关公开信息。
3. 出版社/教材官网、课程官网、教师发布的课件或通知。
4. 培训机构、经验帖、社区总结只能作为参考线索，不能当官方结论。

优先使用 `mcp:exa` 或 `web_search_bing` 做核验。搜索建议：

- `{年份} 408 计算机学科专业基础综合 考试大纲`
- `{院校名} 计算机 408 专业课 考试大纲`
- `{院校名} 计算机学院 研究生招生 专业目录 408`
- `408 计算机学科专业基础综合 数据结构 组成原理 操作系统 计算机网络 分值`

输出时区分：

- **已核验信息**：给出来源摘要。
- **通用 408 复习经验**：说明不是官方变动。
- **用户材料范围**：以用户上传资料为准。

## 四科复习重心

| 科目 | 核心能力 | 常见题型 | 适合可视化 |
|---|---|---|---|
| 数据结构 | 抽象结构、算法过程、复杂度 | 树/图/查找/排序/算法设计 | 树遍历、图算法、排序过程、哈希冲突 |
| 组成原理 | 数据表示、指令执行、存储层次、CPU/I/O | 补码浮点、Cache、指令、流水线 | CPU 数据通路、Cache 地址划分、流水线时序 |
| 操作系统 | 资源管理、并发、内存、文件和 I/O | PV、调度、死锁、页面置换、磁盘调度 | 进程状态、调度队列、页表转换、资源分配图 |
| 计算机网络 | 分层协议、寻址转发、可靠传输、应用协议 | 子网、路由、TCP、DNS/HTTP/DHCP/TLS | 协议流程、包头结构、路由表、交换机转发 |

| 阶段 | 重点 | 方法 | 产物 |

## 题型训练模板

### 数据结构

- 树：先确定遍历序列约束，再还原结构或计算路径。
- 图：先列顶点、边和权，再逐步记录算法状态。
- 查找/排序：写出每一趟状态、比较次数、移动次数、稳定性。
- 算法设计：先给思路和不变量，再写伪代码，最后分析复杂度。

### 组成原理

- 数据表示：明确位数、符号位、阶码/尾数、规格化和舍入规则。
- Cache：先做地址划分，再判映射方式、命中/替换、平均访问时间。
- 指令/CPU：列字段位数、寻址方式、数据通路和控制信号。
- 流水线：画时序表，分清理想周期、停顿、吞吐率和加速比。

### 操作系统

- 调度：列到达时间、服务时间、队列状态、完成/周转/等待时间。
- PV：先找共享资源、临界区和前驱关系，再设计信号量。
- 死锁：资源分配图或银行家算法表格化。
- 内存：分清逻辑地址、页号、页内偏移、物理块号、TLB/缺页。

### 计算机网络

- 子网/CIDR：写二进制前缀、网络地址、广播地址、可用范围。
- 路由：按最长前缀匹配逐项比较，不凭直觉选。
- TCP：画序号、确认号、窗口、状态迁移和拥塞窗口变化。
- 应用协议：按“请求 -> 解析 -> 连接 -> 响应”重建流程。

## 错因诊断模型

每道错题至少打一个标签：

| 错因 | 表现 | 修复方式 |
|---|---|---|
| 概念混淆 | 层次、术语、机制说不清 | 回到概念卡和对比表 |
| 规则漏步 | 算法过程、状态迁移、字段切分漏项 | 做步骤模板 |
| 计算错误 | 单位、位数、边界、进制错误 | 建计算检查清单 |
| 审题错误 | 忽略条件、把问法看错 | 标注题干关键词 |
| 迁移不足 | 会例题，不会变式 | 做同型变式和综合题 |
