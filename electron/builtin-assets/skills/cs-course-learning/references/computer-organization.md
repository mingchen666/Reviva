# 计算机组成原理

## 核心模块

- 数据表示：进制、补码、浮点数、校验码。
- 运算器：定点/浮点运算、溢出判断、ALU。
- 存储系统：主存、Cache、虚拟存储基础、地址映射。
- 指令系统：寻址方式、指令格式、CISC/RISC 基础。
- CPU：数据通路、控制器、流水线、冒险处理。
- 总线与 I/O：中断、DMA、接口。

## 讲解原则

- 先画数据流：数据从哪里来、经过哪些部件、写回哪里。
- 计算题要列公式、字段位数、地址划分和单位换算。
- CPU/流水线题要列周期表或时间线。

## 常见题型

- 补码范围、溢出、浮点表示和规格化。
- Cache 地址划分、命中率、平均访问时间。
- 指令格式字段位数和寻址范围。
- 流水线吞吐率、加速比、冲突处理。
- 中断/DMA 工作过程。

## 易错点

- bit、Byte、字、字长、存储字长混淆。
- Cache 块号、组号、标记位切分错误。
- 补码溢出判断和进位判断混淆。
- 流水线理想时间和实际停顿时间混淆。
